# Logos de Referencia

Os arquivos preservados aqui foram fornecidos para apoiar a identidade visual do produto. Antes de publicar este repositorio, confirmar permissao de redistribuicao das marcas.

## Produto

- `produto/`: marcas principais do Banco Ortopedico e assinatura institucional.

## Entidades

- `entidades/`: logos das entidades do MVP e das entidades que podem ter membros com acesso ao sistema.

Os arquivos desta pasta sao referencias de origem. No repositorio do app, copiar para `public/brand/` apenas as variantes aprovadas e efetivamente usadas. Preservar proporcoes, transparencia e nome original sempre que possivel.

Foram omitidos do conjunto publico os ativos explicitamente sem uso no sistema ou dependentes de um lema anual.
