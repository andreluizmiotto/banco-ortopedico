# Referencias de UX

As imagens recebidas no pacote original foram omitidas desta documentacao publica porque continham nomes reais ou outros dados operacionais. Os fluxos e requisitos relevantes foram reescritos em:

- [Acessibilidade e fluxos](../acessibilidade-e-fluxos.md)
- [Identidade visual](../identidade-visual.md)
- [Requisitos do produto](../../produto/requisitos.md)

Quando forem adicionadas novas referencias visuais:

- usar nomes e quantidades sinteticos;
- nao incluir CPF, telefone, endereco, notificacao real ou dados de producao;
- nao usar logos sem permissao de redistribuicao;
- tratar a imagem como ilustrativa; requisitos normativos permanecem nos documentos Markdown.
